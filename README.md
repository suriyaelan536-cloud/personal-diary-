# Little Pages — Personal Diary Web App

A beginner-friendly diary website built with HTML, CSS, and JavaScript. It lets you create diary entries, choose a mood, view saved entries, and delete entries.

## Features
- Create diary entries with a title, mood, and text
- Save entries in browser local storage
- View entries with date and time
- Delete entries
- Responsive design for laptop and mobile screens

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Write a title and your thoughts, choose a mood, and click **Save my page**.

No installation is required.

## Important privacy note
Entries are stored in local storage in the browser on the device where they are written. They are not synced to GitHub or another account. Do not use this demo to store highly sensitive information. Clearing browser data may remove entries.
